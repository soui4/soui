SOUI on WebAssembly 演示

SApplication + SAppCfg::DoConfig()（render-gdi / imgdecoder-stb 静态组件） + SHostWnd 装载 uires/xml/dlg_main.xml + SResProviderFiles 从 MEMFS 读 uires.idx + emscripten_set_main_loop 驱动 PeekMessage 泵。

画面下半部是一个十二页的 <tabctrl>，按能力分组： 概览（2x2 能力卡）、基础控件（progress / sliderbar / switch / toggle / radio / calendar，以及 combobox 的弹出列表与 listbox）、更多控件（hotkey / ipctrl 与 ratingbar / lightbutton / verificationCodeEdit / grouplist）、MVC （嵌套 <tabctrl> 切换四个视图：listview / tileview / treeview / mclistview 共享同一份 500 行数据，树由 STreeAdapterBase 单独驱动；行模板不再是 一行文本——头像块、两行标题、说明、热度进度条与下载量都是模板里的普通控件，控件只为 可视区建窗口，打乱与追加只 notifyDataSetChanged() 一次）、 列表与树（listctrl / treectrl）、布局（weight / interval / layout_gravity / gravity / pos 绝对定位 / 嵌套，六张卡各自排出可见的子块）、 图形控件（progressRing / speedmeter / waveprogress / qrctrl）、 表格（gridctrl 的固定行列与复选单元格、propgrid 的分组属性树）、 图表（hellocharts 的折线 / 柱状 / 环形饼图，数据模型由宿主交给 视图）、编辑器（<edit> = richedit41、<hexedit>、 <scintilla>）、扩展控件（controls.extend 的 colorizeText / scrolltext，后者演示水平跑马灯与多行垂直切换两种模式）、 Lua 游戏（消消乐 / 俄罗斯方块 / 坦克大战：整页布局、 SVG 皮肤与动画模板都从资源索引取，棋盘格子由 ScriptModule-LUA 在 on_init 里创建，点击与键盘回到脚本）。这些控件分别来自核心、 controls.extend、third-part/richedit41、 third-part/Scintilla 与 components/ScriptModule-LUA， 全部静态链进同一个 wasm 模块——缺一项对应标签就会被静默跳过。
