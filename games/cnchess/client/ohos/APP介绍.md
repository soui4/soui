# 开心象棋（中国象棋鸿蒙版）· APP 介绍

> 包名 `com.soui.happychess` · 基于 SOUI 跨平台 DirectUI 框架 · 适配 HarmonyOS NEXT
> 本介绍所列功能均来自 `games/cnchess` 工程实际代码，非虚构。

---

## 一句话简介

开心象棋是运行在鸿蒙（HarmonyOS NEXT）上的中国象棋对弈应用，基于 SOUI 跨平台框架，复用与 PC / Android 版完全一致的一套 C++ 业务代码，通过 ArkTS + N-API 桥接在鸿蒙原生渲染（Skia）上运行，带来原生的操作手感与跨端一致的棋局体验。

---

## 主要功能

### 1. 联机对战（大厅实时对弈）
- 通过 **WebSocket** 连接中国象棋服务器，进入**大厅**后自由坐桌，与在线棋友实时对弈。
- 对局状态机覆盖「连接中 → 等待开始 → 对局中」全流程，支持断线重连与桌面状态同步。
- 每方**步时计时**（默认 60 秒 / 步），超时自动判负，桌面显示双方倒计时闹钟。

### 2. 人机对战（三档电脑 AI）
- 在**大厅**或**残局**页均可「邀请机器人」入座，一键挑战电脑。
- 提供 **初级 / 中级 / 高级** 三档难度，对应不同的 AI 思考预算（约 0.4s / 0.8s / 1.5s）。
- AI 由服务端 `RobotAIPool` 线程池统一调度，引擎内核 `ChsAIEngine` 采用 PVS（主要变例搜索）+ 置换表 + 杀手/历史启发 + 静态搜索，棋力随难度递增。
- 注：人机对战同样经由服务器，需保持联网。

### 3. 残局挑战
- 内置**残局题库**（`endgames.json`），以难度星级（1–3 星）标注，列表可直接预览与筛选。
- 每个残局固定两桌，可与好友或机器人分别挑战，适合练杀、拆解名局。

### 4. 完整的对局操作
- **悔棋**：请求悔棋并带次数限制，对方确认后回退。
- **求和（和棋）**：发起和棋请求，对方确认 / 拒绝均有专门弹窗处理。
- **认输**：一键认负，快速结束本局。
- **走子交互**：点选棋子高亮可落点，拖动 / 点击落子带动画，支持选子、取消、走子全过程反馈。

### 5. 棋局特效与音效
- **特效动画**：吃大子（`FX_EAT`）、将军（`FX_CHECK`）、绝杀（`FX_MATE`）触发对应视觉特效，关键时刻更有**胜利 GIF 动画**。
- **音效**：落子、吃子等均有音效反馈，并提供顶栏**静音 / 取消静音**开关。

### 6. 个性化与社交
- **登录**：以昵称 + 性别 + 内置头像完成登录，对局中展示双方头像与资料。
- **主题换肤**：通过 `ThemeDownloadManager` **在线下载、解压并应用**主题资源，下载 / 解压进度以统一模态弹窗呈现，换肤即生效。

### 7. 严谨的中国象棋规则
- 走子合法性校验、将军 / 将死判定。
- **长捉（长将）** 等重复局面处理（`GetFarthestRepeat` 计算最远一次重复走棋），贴合竞赛规则。

### 8. 鸿蒙原生体验与跨端一致
- 面向 **HarmonyOS NEXT**，入口为 `EntryAbility`，主页面通过 `SouiScreen` 承载 SOUI 渲染。
- 资源经 **HAP rawfile 直读**（`SetAppResOhosRawFile` / `SetSysResOhosRawFile`），免去运行期资源拷贝。
- 同一份 C++ 棋局 / AI / UI 逻辑在 **Windows / Android / OpenHarmony** 多端共享，行为一致、维护统一。

## 技术架构（简述）

- **UI 框架**：SOUI 5.x（DirectUI）+ Skia 渲染 + STB 图像解码。
- **平台桥接**：`soui-ohos-lib`（HAR）提供 ArkTS 适配层；C++ 侧经 N-API 注册 `libcnchess.so`，由 `SouiPlatformBridge` 启动 SOUI 应用。
- **通信**：WebSocket 二进制协议（`cnchessProtocol.h`），对局消息包括登录、坐桌、走棋、悔棋、求和、认输、结束等。
- **AI**：服务端 `ChsAIEngine`（搜索 + 置换表 + 启发式），按难度分配思考预算。
- **工程位置**：`games/cnchess/client/ohos`（移植工程），共享 `games/cnchess/client` 下的 C++ 源码（`MainDlg` / `ChessGame` / `ChessBoard` 等）。
