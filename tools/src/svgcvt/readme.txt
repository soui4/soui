========================================================================
svg2png 工具用法
========================================================================
将 SVG 渲染为位图，并导出 png / ico / icns 三种格式。

  用法：
    svg2png -i <input.svg> -o <output.[png|ico|icns]> [-s <size>]

  参数：
    -i  输入 SVG 路径（必须以 .svg 结尾）
    -o  输出文件路径，扩展名决定格式：
          .png  单尺寸位图（默认）
          .ico  多尺寸图标（Windows），内嵌 16/24/32/48/64/128/256 各尺寸 PNG
          .icns macOS 图标，内嵌 32/64/128/256/512/1024 各尺寸 PNG
    -s  目标尺寸（仅对 .png 生效；ico/icns 为多分辨率，忽略此参数）

  说明：
    - 渲染保持 SVG 原始宽高比（-s 指定宽度，高度按比例计算）。
    - 未指定 -o 时，默认输出为 <input>_<size>.png。
    - ico/icns 内部直接内嵌 PNG（保留 alpha 透明通道），无需额外依赖。
